choo 🚂

UK train times from your terminal

uvx choo pypi.org/project/choo

Quick Start

$ choo auth                          # set up API credentials
$ choo config alias.home HIB          # save your home station
$ choo config alias.work LBG          # save your work station
$ choo                                # next trains home → work
$ choo choo                            # reverse: work → home

Commands

choo                                          │ = next home work (bare default)
choo --on tomorrow                             │ bare default accepts all next flags
choo FROM TO                                  │ choo home work (implicit next)
choo choo                                      │ = next work home (reverse commute!)
│
├─ next                                          │ = next home work
│  next FROM                                     │ TO defaults to work alias
│  next FROM TO                                 │ choo next KGX YRK
│  next FROM TO --at HH:MM                     │ choo next KGX YRK --at 14:30
│  next FROM TO --on DATE                       │ choo next KGX YRK --on tomorrow
│  next FROM TO --count N                       │ default: 5 (configurable)
│  next FROM TO --arrivals                      │
│  next FROM TO --json                           │
│
├─ board                                         │ = board home
│  board FROM                                    │ choo board KGX
│  board FROM TO                                │ choo board KGX YRK (filtered)
│  board FROM --at --on --arrivals --json       │ same flags as next
│
├─ service UID                                  │ choo service C41053
│  service UID --on DATE --json                │
│
├─ config                                        │ list all config (like git config)
│  config KEY                                    │ get a value
│  config KEY VALUE                              │ set a value
│  config --unset KEY                           │ remove a key
│
├─ auth                                          │ guided credential setup
│
└─ stations
   stations update                               │ fetch fresh data from GitHub
   stations list                                 │ show count of loaded stations

Smart Behaviours

choo choo = come home

Reverses home/work. Next trains from work → home.

Late night → tomorrow

No trains today? Auto-shows tomorrow's first services.

Fuzzy station names

2,599 stations. "kings cross" → KGX. "paddington" → PAD.

Defaults everywhere

Bare choo = next home work. Bare board = board home. Now is default time.
