GET Location Search

GET /search/{station}{/to/toStation}{/yyyy/mm/dd}{/HHMM}{/arrivals}
ParameterType
stationstr CRS coderequired
toStationstr CRS codeoptional
datedate yyyy/mm/ddoptional
timestr HHMMoptional
arrivalsflagoptional

Examples:

/search/HIB
/search/HIB/to/BHM
/search/HIB/2026/03/13/1430
/search/HIB/2026/03/13/arrivals

GET Service Information

GET /service/{serviceUid}/{yyyy/mm/dd}
ParameterType
serviceUidstr [A-Z]\d{5}required
datedate yyyy/mm/ddrequired

Example:

/service/A12345/2026/03/13

Returns the full calling pattern for a service: every stop with scheduled and realtime times, platforms, lateness, and cancellation info.
